# An effective axiomatization boundary for finite raw variation

## 1. Language, models, and validity

Let P be a countably infinite set of propositional atoms. **Normal antecedents** A are the free Boolean syntax on P, generated by negation, conjunction and disjunction. They contain no conditionals and are not quotiented by classical equivalence. **State formulas** phi are generated by atoms, the classical Boolean connectives, and A > phi. Thus consequents can be nested arbitrarily, while antecedents remain normal formulas.

A finite local raw-variation model has a nonempty finite full product W=product_{c in C} D_c, with C finite, a support S_p contained in C for each relevant atom, and a truth set P_p local to S_p. Coordinates and domain sizes are not bounded in advance. Interpret A > phi universally over the raw exact-verifier successors R_A(w) defined in [the variation note](variation-centering-and-import.md); retain the disjunction-fusion branch and omit strong centering. State-formula Boolean connectives have their ordinary truth-functional meaning.

A formula is **finite-valid** if it holds at every world of every such finite model, with arbitrary local supports and local truth sets. A formula is **finite-satisfiable** if it holds at some world of one such model. These are formula decision problems, not the finite explicit input-data realization problem CBC.

**Main theorem.** Finite-valid formulas of this language are not recursively enumerable. Consequently there is no sound and weakly complete effective proof system whose theorems are generated by finite proofs. The obstruction already occurs in the fragment with three fixed antecedents of the form q_i OR NOT q_i, and still holds if models are restricted to three coordinate factors with unbounded finite domain sizes. It does not require complicated verifier expressions, non-tautologous antecedents, or a left-nested conditional.

The proof gives an exact translation of finite product-modal satisfiability, including a finite covering argument that handles arbitrary overlapping supports. Merely observing that independent-coordinate models form a subclass would not prove this result.

## 2. Tautological antecedents expose support modalities

Choose distinct fresh marker atoms q_1,...,q_k, never used as ordinary data atoms in the modal formulas to be translated. Abbreviate

    [i] phi := (q_i OR NOT q_i) > phi.

**Lemma 1.** In every local raw model, the successor relation of this antecedent is exactly

    E_i(w,v) iff w and v agree outside S_{q_i}.

**Proof.** At each v, exactly one of q_i and NOT q_i is true, and its exact verifier support is S_{q_i}. The other disjunct has no positive verifier there. Their disjunction therefore has the singleton support family {S_{q_i}}; the fusion branch contributes nothing because one family is empty. The raw successor definition gives E_i. This argument does not require the marker truth value to be constant. QED.

Markers may all be constantly true in witnessing models, but their stipulated supports need not be empty: the semantics does not require supports to be minimal. The recovered positive/negative atomic relation still records their entire stipulated support.

Let ML_k be ordinary k-modal propositional logic, with arbitrary data valuations. Translate it effectively by preserving data atoms and Boolean connectives and replacing each modal box with the abbreviation above. Write tau_k for this translation. Its size is linear up to the fixed names of the k markers.

## 3. Finite product covers for overlapping supports

A rooted S5 product model has domain X_1 times ... times X_k, with the i-th accessibility relation changing only the i-th coordinate, arbitrarily. Data valuations are unrestricted. We use nonempty finite X_i for the finite version.

**Lemma 2 (finite cover).** Let W be a finite full product, with any coordinate-subset equivalences E_1,...,E_k obtained from supports S_1,...,S_k. For every w in W, the component reachable from w under these relations is a surjective bounded-morphic image of a finite rooted k-dimensional S5 product.

**Proof.** Put U=union_i S_i. The component W_w consists precisely of worlds agreeing with w outside U. One inclusion is immediate. For the other, any target coordinates in U can be set successively using the supports; at each step preserve already correct coordinates, since each support update permits arbitrary values on its coordinates.

For each c in U, label D_c by the cyclic group Z_{d_c}, where d_c=|D_c|; this includes d_c=1. Form the new i-th domain

    X_i = product_{c in S_i} Z_{d_c},

taking an empty product to be a singleton. A source world x has an entry x_{i,c} for each incidence c in S_i. Define h: product_i X_i -> W_w by

    h(x)_c = sum_{i: c in S_i} x_{i,c} modulo d_c   (c in U),
    h(x)_c = w_c                                 (c outside U).

The group labels are identified back with the original domain values. The map is onto: for each c choose one incident i, put the desired value in that copy, and put zero in the others. Choices for different c are independent, even when their selected copies lie in the same X_i.

For the forth property, changing only source coordinate i changes h(x) only inside S_i, so x R_i x' implies h(x) E_i h(x'). For the back property, suppose h(x) E_i v. Keep all source factors j != i unchanged, and for each c in S_i set

    x'_{i,c} = v_c - sum_{j != i: c in S_j} x_{j,c} modulo d_c.

Then x R_i x' and h(x')=v. Coordinates outside S_i already agree. Thus h is a surjective bounded morphism for all k relations. All domains remain finite. QED.

This explicit cover is what prevents overlap, equal supports, empty supports, or hidden background coordinates from invalidating the modal translation. It is a cover, not necessarily an isomorphism or a same-world representation.

**Theorem 3 (exact modal fragment).** For every ML_k formula theta,

    theta is satisfiable in a finite rooted S5^k product
    iff tau_k(theta) is satisfiable in a finite local raw model.

The corresponding finite-validity equivalence also holds.

**Proof, product to raw.** Use the k product coordinates themselves. Give q_i support {i} and constant true valuation. Give each data atom full support, allowing its arbitrary product valuation. Lemma 1 and induction on theta establish truth preservation.

**Proof, raw to product.** At a satisfying raw world w, restrict to W_w for the k marker supports. Truth of the translated modal fragment is unchanged: all its transitions stay inside this component. Apply Lemma 2 and pull each data valuation back along h. The standard bounded-morphism induction, using forth for boxes and back for their converses, proves truth preservation at every source world. Some source world maps to w by surjectivity.

The resulting structure is an ordinary modal model. Its pulled-back data valuations need not satisfy any extra locality condition; none is imposed in product modal logic. We do not silently assume that original data supports remain unchanged on the cover. The reverse construction, where locality is required, assigned full support explicitly. Finally apply the satisfiability equivalence to NOT theta for validity. QED.

## 4. Non-enumerability and consequences

**Classical input theorem [TW12, Section 4.1, Theorem 1].** Satisfiability over finite rooted products S5^k is undecidable for k >= 3. Their definition is a Cartesian product of universal relations, not an arbitrary multimodal S5 fusion. The theorem explicitly distinguishes finite from unrestricted models. Its proof discussion invokes finite semigroups or a finite-model-preserving route from the three-variable Trakhtenbrot problem.

**Proof of the main theorem.** Finite product-modal satisfiability is recursively enumerable: enumerate finite domain sizes, all valuations of the finitely many data atoms in a formula, and all designated worlds, and evaluate the formula. If its finite-valid formulas were also recursively enumerable, dovetail the search for a finite model of theta with the enumeration of finite-valid formulas until NOT theta appears. Exactly one search would halt, deciding finite satisfiability, contrary to the input theorem for k=3.

Thus finite S5^3 validity is not recursively enumerable. By Theorem 3 it is exactly the inverse image of finite raw validity under the computable translation tau_3. An inverse image of a recursively enumerable set under a computable map is recursively enumerable. Therefore finite raw validity is not recursively enumerable.

Any proof system with effectively enumerable finite proofs has recursively enumerable theorems. If sound and weakly complete for finite raw validity, that theorem set would be precisely finite raw validity, contradicting the result. This already concerns theorems from no premises; a claim of effective strong completeness cannot avoid it. QED.

**Corollaries.**

- Finite raw satisfiability is recursively enumerable but undecidable. To enumerate raw models, enumerate finite products, support masks, and local truth tables for the finitely many atoms occurring in the input. Exact-verifier evaluation terminates in every enumerated model. Theorem 3 supplies undecidability.
- There is no computable bound on finite countermodel size as a function of formula length for non-finite-valid formulas. Such a bound would permit exhaustive search and decide finite satisfiability. For a fixed world bound there are only finitely many relevant product representations after removing singleton coordinates, and they can be enumerated effectively.
- No terminating, complete finite-countermodel search or filtration with a computable uniform size bound can cover this full class. Sound incomplete rules and terminating procedures for smaller fragments remain possible.
- CBC NP-completeness remains consistent with this theorem: CBC takes a supplied finite world set and explicit observations, whereas formula satisfiability quantifies over all finite domain sizes.

The result excludes effective systems with finite proofs, not a non-effective list of all valid formulas as axioms, arbitrary infinitary rules, or completeness after changing the semantic class. It also does not by itself prove a non-enumerability result for validity over infinite models.

## 5. A sharp positive boundary within the reset fragment

For k=1 or k=2, the reset-only fragment has a familiar natural Hilbert calculus. Use propositional tautologies and, for each box i, the normal S5 schemes:

    K: [i](phi -> psi) -> ([i]phi -> [i]psi)
    T: [i]phi -> phi
    4: [i]phi -> [i][i]phi
    5: NOT [i]phi -> [i]NOT [i]phi.

For k=2 add commutation

    [1][2]phi <-> [2][1]phi.

Rules are modus ponens, necessitation for each box, and substitution of reset-fragment formulas for the ordinary data atoms. Marker atoms are fixed syntactic parameters and are not among those substitution variables.

The standard S5 and S5 times S5 product completeness results [BH], including completeness for finite square products in dimension two, together with Theorem 3 make this calculus sound and weakly complete for the corresponding finite raw reset fragment. These modal axioms and their completeness are classical, not a new axiomatization claim. In dimension three, merely retaining S5 and pairwise commutation is not product-complete, even for unrestricted models [K02]; for finite validity, the stronger non-enumerability obstruction above applies.

The full raw language continues to validate SDA, appropriate MP, and import, while AS, SEA, CC and export have the countermodels already recorded. None of those results is removed. The transfer theorem explains why adding an effectively enumerable collection of further finitary rules cannot yield completeness for all finite raw models: a tiny tautological-antecedent fragment is already an obstruction.

## Comparison with existing calculi

Briggs' *Interventionist Counterfactuals* gives a sound and complete calculus for recursive structural-equation models. Its assignment-style interventions and determinacy assumptions differ from arbitrary local predicates with possibly many exact support assignments; that completeness theorem cannot simply be imported. Fine and Jago's calculus for exact entailment concerns truthmaker entailment, rather than the nested update modalities considered here. Positive results for finite, fixed-variable/value causal-team signatures likewise do not contradict a theorem whose coordinate-domain sizes range over all finite values. The obstruction identified here is already classical product-modal complexity inside the raw conditional language, not a claim that hyperintensionality alone prevents axiomatization.

## Reproducible cover checks

Run `python models/check_modal_cover.py`. It checks 792 support/domain patterns, including empty, equal and overlapping supports, singleton and nonbinary domains, and every triple of supports on the Boolean three-cube. All covers are onto the correct generated component and satisfy exact successor-image equality. The run checks 324,369 source edges and 1,983,006 nested modal formula/world evaluations, and separately compares tautological resets with the existing exact-verifier evaluator using arbitrary local marker truth sets. These checks support the cover and translation proofs; they cannot prove undecidability or non-enumerability.
